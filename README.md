## Tasks

### Task 1 — Project Setup + Data Ingestion (ETL) ✅
**File:** `data_ingestion.py`

- Loads all 10 CSV datasets from `data/raw/`
- Prints `.shape`, `.dtypes`, and `.head()` for each
- Documents anomalies (missing values, duplicates, range violations) → `reports/data_quality_summary.md`
- Explores `fund_master`: unique fund houses, categories, sub-categories, risk grades
- Validates AMFI codes: confirms every code in `fund_master` exists in `nav_history`

### Task 2 — Data Cleaning + SQL Database Design ✅
**File:** `data_cleaning.py`

- **Cleans nav_history.csv**: parse dates, sort, forward-fill weekends/holidays, deduplicate, validate NAV > 0
- **Cleans investor_transactions.csv**: standardise transaction_type, validate amount > 0, fix dates, KYC enum check
- **Cleans scheme_performance.csv**: validate return columns numeric, flag anomalies, check expense_ratio range [0.1–2.5]
- **Saves 10 cleaned CSVs** → `data/processed/`
- **Designs SQLite star schema** (dim_fund, dim_date, fact_nav, fact_transactions, fact_performance, fact_aum)
- **Loads DB** → `bluestock_mf.db` via sqlite3 (row-count verified)
- **Writes** `sql/schema.sql`, `sql/queries.sql` (10 analytical queries), `reports/data_dictionary.md`

## Setup & Usage

```bash
# 1. Create / activate virtual environment
python3 -m venv .venv
source .venv/bin/activate          # macOS/Linux
# .venv\Scripts\activate           # Windows

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run Task 1 — Data Ingestion & ETL
python data_ingestion.py

# 4. Fetch live NAV data (optional, requires internet)
python live_nav_fetch.py

# 5. Run Task 2 — Data Cleaning + SQLite DB
python data_cleaning.py

# 6. Run Task 3 — EDA (generates 15 charts)
python eda_analysis.py
```

### Run all tasks sequentially
```bash
python data_ingestion.py && python data_cleaning.py && python eda_analysis.py
```

## Key Insights (from EDA)
- SIP inflows hit ATH of **₹31,002 Cr in Dec 2025**
- Total folios grew **97%** (13.26 Cr → 26.12 Cr) over the project period
- **2023 was a bull-run year** — average NAV grew ~14.3% YoY
- **26–35 age group** is the dominant investor cohort (~41%)
- **Banking** is the most concentrated sector in equity fund portfolios
- **Direct plans** save ~0.57% in expense ratio vs Regular plans
