# Deployment Guide
# Capstone Project - I | Bluestock Mutual Fund Analytics

## Current Architecture Assessment

The project uses:
- Pure Python scripts (no web framework)
- Static HTML dashboard (`dashboard/bluestock_mf_dashboard.html`)
- SQLite database (`bluestock_mf.db`)
- matplotlib/seaborn for chart generation

**Recommended deployment approach:** Static site hosting for the dashboard + optional Streamlit conversion for interactivity.

---

## Option A — Static HTML Dashboard (Current, Zero-Cost)

The existing dashboard is a self-contained HTML file with embedded JavaScript and chart data.

### GitHub Pages

```bash
# 1. Create a gh-pages branch or use /docs folder
mkdir docs
cp dashboard/bluestock_mf_dashboard.html docs/index.html
cp -r dashboard/page*.png docs/

# 2. Push to GitHub
git add docs/
git commit -m "Add dashboard for GitHub Pages"
git push origin main

# 3. In GitHub repo Settings → Pages → Source: main branch /docs
# Dashboard URL: https://<username>.github.io/<repo-name>/
```

### Netlify (Drag & Drop)

1. Go to https://app.netlify.com
2. Drag the `dashboard/` folder onto the Netlify deploy area
3. Your dashboard is live in < 60 seconds at a `*.netlify.app` URL

## Option B — Streamlit Web App (Recommended for Interactivity)

Convert the pipeline to a Streamlit app for live filtering and real-time data.

### Install Streamlit

```bash
pip install streamlit plotly
```

### Run Locally

```bash
# After creating streamlit_app.py (see below)
streamlit run streamlit_app.py
```

### Deploy on Streamlit Cloud

1. Push code to GitHub (public or private repo)
2. Go to https://share.streamlit.io
3. Click **New app** → select repo → set main file to `streamlit_app.py`
4. Click **Deploy** — live URL in ~2 minutes

### Deploy on Render

```bash
# Create render.yaml in project root:
cat > render.yaml << 'EOF'
services:
  - type: web
    name: bluestock-mf-analytics
    env: python
    buildCommand: pip install -r requirements_deploy.txt
    startCommand: streamlit run streamlit_app.py --server.port $PORT --server.address 0.0.0.0
EOF
```

1. Push to GitHub
2. Go to https://render.com → New → Web Service
3. Connect GitHub repo
4. Render auto-detects `render.yaml` and deploys

### Deploy on Railway

```bash
# Create Procfile
echo "web: streamlit run streamlit_app.py --server.port \$PORT --server.address 0.0.0.0" > Procfile
```

1. Install Railway CLI: `npm install -g @railway/cli`
2. `railway login`
3. `railway init` (in project directory)
4. `railway up`

## Deployment Checklist

### Pre-Deployment

- [ ] All Python files run without errors
- [ ] `python run_pipeline.py` completes all 7 steps
- [ ] `dashboard/bluestock_mf_dashboard.html` opens and renders correctly
- [ ] `requirements_deploy.txt` contains all runtime dependencies
- [ ] `.env.example` is committed (`.env` is in `.gitignore`)
- [ ] No API keys or credentials in source code
- [ ] `README.md` is complete and accurate

### Git Hygiene

```bash
# Create .gitignore
cat > .gitignore << 'EOF'
.venv/
__pycache__/
*.pyc
.env
*.log
.DS_Store
EOF
```

### Files to EXCLUDE from deployment

- `.venv/` (virtual environment)
- `*.pyc` (compiled Python)
- `.env` (secrets)
- `bluestock_mf.db` (can be regenerated by pipeline)

### Files to INCLUDE

- All `.py` source files
- `data/raw/` (raw CSVs — source of truth)
- `requirements_deploy.txt`
- `.env.example`
- `README.md`
- `dashboard/bluestock_mf_dashboard.html`
- `reports/` (generated outputs)

## Environment Variables in Production

For cloud platforms (Render, Railway, Streamlit Cloud):

| Variable | Default | Description |
|---|---|---|
| RISK_FREE_RATE | 0.065 | Annual risk-free rate |
| TRADING_DAYS | 252 | Annualisation factor |
| VAR_CONFIDENCE | 0.95 | VaR confidence level |
| RECOMMENDER_TOP_N | 3 | Funds per recommendation |
| LOG_LEVEL | INFO | Logging verbosity |

Set these in the platform's **Environment Variables** section — never in source code.
